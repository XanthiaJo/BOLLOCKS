Memory LLM

The "memory-writer": a second AI that reads new chat and decides what to store. These settings control how it runs.
Extraction profile (required)
Which API connection the memory-writer uses (set up under Connection). Smart memory can't run until you pick one — a small/cheap model is usually plenty.
Generation budget (tokens)How much the memory-writer may write per run. ~4 characters ≈ 1 token. Default: 2000.
No cap on the writer's reply. Overrides the budget above — can be slow or expensive on paid APIs. Log a line on the server each time extraction runs — handy to confirm it's working. On: memories reach the AI as one "Memories:" block. Off: split into "what happened here" (shared) and "what this character remembers" (personal). The writer tags each memory with keywords; a memory is only added to the prompt when a keyword appeared in the last few messages. Cheaper prompts, occasionally misses context. Automatically raise the injection token budget (below) if stored memories keep getting cut off.
Injection refresh every N AI messagesOnly add memories to the prompt every Nth reply — saves tokens on the replies in between. 1 = every reply (default).

Extraction

When and how new chat gets turned into stored memories.
Extract after every N new messagesHow often the memory-writer runs. Smaller = more up-to-date but more API calls. Default: 10.
Max stored smart memories (total)Overall cap across all types — oldest are forgotten first. 0 = unlimited. Default: 50.
Caps per memory type; the oldest of that type drop first. 0 = no per-type limit (the total cap still applies). Facts = things that are true; events = things that happened; relationships = how characters feel about each other; preferences = likes/dislikes. Default: 50 each.

Extraction prompt template
Custom instructions for the memory-writer (e.g. focus on plot, ignore OOC). Leave blank for the built-in prompt.
Context threshold (%)Also run extraction early once the chat fills this % of the model's context — so nothing important is lost before old messages get trimmed. Default: 80.
Response length (tokens)Fallback reply length — only used when the generation budget above is unset. Usually safe to leave alone. Default: 2000.
